## 요약

2020년에 원인을 알 수 없던 서버 성능 저하 두 건을 함께 맡았습니다. 하나는 특정 제조사 서버 약 200대의 CPU 온도 상승, 다른 하나는 특정 모델에서 CPU P-state 기능과 관련된 메모리 성능 저하였습니다. 두 건 모두 처음에는 하드웨어 고장을 의심했지만, 바깥쪽 원인부터 하나씩 지워 가며 들어가 보니 원인은 firmware(BMC, UEFI)에 있었습니다.

## CPU 온도 이상 (2020.05 – 08)

| 가설 | 확인한 방법 | 결과 |
|---|---|---|
| 과부하 | 서버 환경과 부하, 성능 모니터링 도구 | 과부하 아님 |
| 외부 환경 | 서버 환경 확인 | 외부 요인 아님 |
| 냉각 부족 | Enhanced Cooling Mode, 팬 속도를 바꿔 가며 냉각이 가장 잘 되는 값 찾기 | 증상 완화, 근본 원인은 아님 |
| BMC firmware | 제조사와 상세 로그 분석 | iLO firmware 버그 확인 |

1. 서버 환경과 부하를 확인하고 성능 모니터링 도구로 살펴봤습니다. 과부하가 원인은 아니었습니다.
2. 서버 설정에서 Enhanced Cooling Mode를 켜고 팬 속도를 바꿔 가며 냉각이 가장 잘 되는 값을 찾았습니다. 이것으로 증상을 먼저 줄였습니다.
3. 제조사와 함께 상세 로그를 분석해 iLO firmware 버그를 확인했습니다.
4. iLO firmware를 최신 버전으로 올려 CPU 온도와 성능을 정상화했습니다.
5. 같은 모델과 firmware 조합의 서버에도 미리 업데이트해 같은 문제가 다시 생기지 않게 했습니다.

## 메모리 성능 저하 (2020.04 – 07)

| 가설 | 확인한 방법 | 결과 |
|---|---|---|
| 부품 불량·호환성 | CPU, 메모리, 시스템 보드를 새 부품으로 교체 후 Intel MLC로 측정 | 같은 증상, 하드웨어 고장 아님 |
| CPU와 메모리 사이 동작 | 메모리 구성을 최소로 줄여 가며 실험 | CPU P-state와 관련된 것으로 좁힘 |
| 설정 | UEFI 설정 초기화 후 IDC 환경에 맞게 재조정 | 완전히 해결되지 않음 |
| firmware | UEFI, BMC(IMM) firmware 최신화와 로그 분석, 제조사 글로벌 기술지원 협업 | UEFI v2.31로 해결 |

1. CPU, 메모리, 시스템 보드를 새 부품으로 교체하고 Intel MLC로 메모리 성능을 다시 쟀습니다.
2. 메모리 구성을 최소로 줄여 가며 CPU와 메모리 사이의 영향을 확인했습니다.
3. UEFI 설정을 초기화하고 IDC 환경에 맞게 다시 맞췄습니다.
4. UEFI와 BMC(IMM) firmware를 최신으로 올리고, 영향받은 서버 로그를 분석해 다른 서버에 미칠 영향도 확인했습니다.
5. 제조사 글로벌 기술지원팀과 자료를 주고받으며 원인을 좁혔고, UEFI v2.31로 해결했습니다.
6. 증상이 없던 서버에도 BMC firmware를 미리 올려 잠재적인 장애를 막았습니다.

## 쓴 도구

| 도구 | 용도 |
|---|---|
| 성능 모니터링 도구 | 부하와 응답 지연 확인, 과부하 배제 |
| Intel MLC (Memory Latency Checker) | 부품 교체 전후 메모리 성능 비교 |
| BMC(iLO, IMM) 로그 | 온도, 팬, 하드웨어 이벤트 확인과 제조사 분석 자료 |
| UEFI·BIOS 설정 | 냉각 모드, 팬 속도 조정, UEFI 설정 초기화와 재조정 |
| firmware 버전 목록 | 같은 모델·조합 서버를 골라 선제 적용 |

## 정리

- 두 건 모두 처음에는 하드웨어 고장을 의심했지만 원인은 firmware에 있었습니다. 이후로는 부품 교체 전에 firmware 버전과 전력·냉각 설정부터 확인합니다.
- 증상을 먼저 줄이는 조치(냉각 설정)와 원인을 찾는 일을 나눠서 진행했습니다. 서비스 영향을 줄이면서 원인을 찾을 시간을 벌었습니다.
- 증상이 난 서버만 고치지 않고, 같은 모델과 firmware 조합을 가진 서버 전체에 조치를 적용했습니다.

## GPU 노드에 옮기면

GPU 노드에서도 thermal throttling, 전력 제한, driver·VBIOS 버전 차이로 같은 유형의 성능 저하가 생깁니다. 같은 순서로 확인할 수 있습니다.

| 서버에서 본 것 | GPU 노드에서 볼 것 |
|---|---|
| 부하와 외부 요인 | 학습 작업 부하, 랙·노드 온도 비교 |
| 냉각 설정과 팬 | GPU 온도와 throttle 사유(`nvidia-smi -q -d TEMPERATURE,PERFORMANCE`) |
| 전력 관리(P-state) | GPU P-state, 전력 제한, clock 설정 |
| firmware 버전 | driver, VBIOS, BMC firmware 버전을 같은 조합끼리 비교 |
| 부품 교체 후 재측정 | `dcgmi diag`, `nccl-tests`로 재측정 |
