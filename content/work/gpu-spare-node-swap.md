## 배경

- 약 200노드 규모의 H200 학습 클러스터는 GPU 마다 NIC 하나가 같은 번호의 leaf 스위치로 가는 **rail-optimized** 구조다.
- 노드가 고장 났을 때 예비 노드를 아무 포트에나 붙이면 rail 정렬이 깨져, 집단 통신이 다른 경로를 타게 된다.

## 한 일

- 고장 노드를 빼고, 예비 노드를 **그 자리로 물리 이전**했다.
- 재마운트, 전원 연결, 광 케이블 재결선까지 현장에서 직접 수행
- 2개월 동안 9번 반복

## 판단

- 예비 leaf 에 바로 붙이면 빠르지만 rail 정렬이 깨진다. 시간이 더 들어도 **원래 자리로 옮기는 쪽**을 택했다.
- 작업 1건당 정지 시간은 기록이 남아 있지 않다.

## 배운 것

- GPU 클러스터에서 "노드 교체"는 서버 한 대를 바꾸는 일이 아니라 **네트워크 위치를 지키는 일**이다.
