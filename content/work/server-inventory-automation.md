## 배경

- 대규모 서버 환경에서 서버 정보를 손으로 모으다 보니 대당 수 분씩 걸렸고 입력 오류가 잦았다.
- 여러 정보를 빠르게 모으고 검증하기 어려웠다.

## 한 일

- 모든 서버 작업을 기록·추적하는 ticket 기반 정보 관리 시스템 구축
- dmidecode, MegaRAID 등 수집 도구를 모듈화해 명령 하나로 통합
- Ansible 로 네트워크상의 서버에 접속해 정보를 자동 수집
- 수집 결과를 Excel 보고서로 변환

## 결과

- 사람이 대당 수 분씩 하던 검수가 자동 수집으로 바뀌었다.
- 모든 서버를 같은 기준으로 빠짐없이 검사하게 됐고, 입력 실수가 줄었다.
- 작업 기록이 쌓이면서 팀 간 공유와 장애 추세 분석이 쉬워졌다.
