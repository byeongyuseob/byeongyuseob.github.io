## 알림 발신 게이트웨이 (2025.11 – 현재)

서비스마다 메신저 Bot 키와 메일 설정을 따로 갖고 있어서 키 관리와 발송 이력 확인이 어려웠습니다.

- 사내 서비스가 서비스 토큰 하나로 업무 메신저와 메일을 보낼 수 있는 발신 전용 게이트웨이 개발
- 서비스별 토큰과 발송 기록으로 어떤 서비스가 무엇을 보냈는지 확인 가능
- 키는 게이트웨이에만 두어, 키를 바꿀 때 한 곳만 수정하면 되도록 구성

## 운영 데이터 조회 MCP 서버 (2026.07)

랙, 서버, 자산 정보를 찾으려면 여러 사내 시스템을 따로 조회해야 했습니다.

- 사내 운영 API를 읽기 전용 MCP 도구 10개로 정리
- 자연어 질문은 사내 LLM이 해석하고, 실제 조회는 정해진 규칙대로 실행
- 자산 조회는 한 번에 최대 3건으로 제한하고, 이 제한은 LLM이 바꿀 수 없도록 코드에 고정
- LLM이 잘못된 인자로 조회하는 일을 막는 데 중점을 둠

## 배포 서버 보안·자원 점검 (2026.10)

- 호스트와 실행 중인 컨테이너의 설치 패키지를 수집해 CVE 데이터와 대조하는 대시보드
- 사내에서 지원하는 base image 목록을 관리해 교체 대상 확인
- 1분 간격 자원 기록과 메일 알림 ([관련 글](/posts/cron-resource-log/))
