## 근무일지 통합 (2026.07 – 현재)

- 업무일지 · 인수인계 · 인프라 점검이 따로 있어 같은 근무자와 날짜를 세 번 입력했고 결재도 여러 번 받았다.
- 현행 데이터를 조사해 근무조 · 순찰 회차 · 인수인계 시점 · 결재 규칙을 정리하고, **IDC 하나 = 근무일 하나의 일지**로 설계
- IDC 14곳 지원, IDC 별 근무 형태(24시간 / 주간 전용) · 체크리스트를 관리 화면에서 설정
- 화면 시안 여러 안을 비교해 확정 → 구현 → 사내 시험 배포. 이전 버전은 폐기하고 새로 설계했다.

## SLA 대시보드 (2026.10 – 현재)

- 사내 장애 · 작업 관리 시스템의 실제 데이터로 SLA 지표를 계산해 대시보드로 운영
- 팀장 · 관리자가 **잠깐 열어 보고 닫는** 사용 방식에 맞춰 요약 중심으로 설계

## 예외 기반 점검 전환 (2026.10, 분석 · 시제품)

- 하루 여러 번 사람이 도는 인프라 점검 기록을 분석하니, 점검이 업무에서 큰 비중인데 결과는 대부분 "이상 없음"이었다.
- 시설 관리 시스템의 랙 온습도 데이터로 **온도 변화 · Hot Spot** 을 감지하는 규칙을 시제품으로 만들고, 일지에 "점검 추천 구역"을 제안하는 화면을 그렸다.
- 목표: 사람은 물리 항목만 보고, 온습도 · 출입 · 알람은 자동 확인으로 넘긴다.
