> 2025.08 – 2025.10, 현장 구축·운영. 관련 프로젝트: [H200 학습 클러스터 구축·운영](/work/h200-training-cluster/)

## 요약

약 200노드 규모 H200 학습 클러스터에서 고장 노드를 예비 노드로 바꿀 때, 빈 포트에 바로 연결하지 않고 고장 노드 자리로 예비 노드를 옮겨 설치했습니다. 그래야 GPU들이 원래 rail leaf에 그대로 붙습니다. 두 달 동안 9번 진행했고, 같은 기간에 InfiniBand 광모듈 7천여 개 교체도 함께 진행했습니다.

## 클러스터 조건

| 항목 | 내용 |
|---|---|
| 서버 | 8-GPU HGX H200, 약 200노드 |
| GPU 네트워크 | NDR 400G InfiniBand fat-tree, GPU 1개당 NIC 1개 |
| 배치 방식 | Rail-optimized, 1:1 non-blocking |

각 노드의 GPU 0번은 rail 0 leaf로, GPU 1번은 rail 1 leaf로 가는 식으로 같은 번호끼리 묶입니다. 노드 사이 같은 번호 GPU 통신이 leaf 하나 안에서 끝납니다.

## 두 가지 방법

{{< rail >}}

| 방법 | 장점 | 문제 |
|---|---|---|
| 빈 포트에 예비 노드 연결 | 케이블만 꽂으면 되어 빠름 | GPU들이 원래와 다른 rail leaf에 붙어, 그 노드가 들어간 작업은 통신 경로가 달라짐 |
| 고장 자리로 예비 노드 이전 | rail 배치가 그대로 유지됨 | 재마운트, 전원, 광 케이블 재결선까지 해야 해서 손이 많이 감 |

위 도식에서 모드를 바꾸면 두 방법의 연결 차이를 볼 수 있습니다.

- 고장 노드를 빼고 그 자리에 예비 노드를 옮겨 설치했습니다.
- 재마운트, 전원, 광 케이블 재결선까지 직접 했습니다.
- 약 200노드가 한 작업으로 돌아서, 학습을 멈추고 노드를 옮긴 뒤 체크포인트에서 다시 시작했습니다.
- 2025.08부터 10월까지 9번 진행했습니다. 작업 1건당 정지 시간은 기록이 남아 있지 않습니다.

## 같은 기간: 광모듈 교체

같은 기간에 NDR 400G InfiniBand 네트워크의 서드파티 광모듈을 NVIDIA 정품으로 바꿨습니다. 7천여 개를 교체하면서 케이블맵을 기준으로 범위와 순서를 관리했습니다. 케이블맵에는 노드, 포트, 상대 스위치 포트, 광모듈 수량이 들어 있어서, 노드를 옮길 때도 어느 링크를 다시 연결해야 하는지 같은 자료로 확인할 수 있었습니다.

## 정리

- GPU 클러스터에서는 노드를 바꿀 때 서버만 맞추면 끝나지 않고, 네트워크상의 위치까지 맞춰야 했습니다.
- 빠른 방법보다 학습 작업의 통신 경로를 일정하게 지키는 쪽을 골랐습니다.
- 앞으로는 교체 후 `nccl-tests`로 통신 성능을 확인하는 절차까지 직접 해 볼 계획입니다.
