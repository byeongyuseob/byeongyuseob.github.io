> 2020.05 – 2020.08 · Contributor · 관련 프로젝트: [CPU 온도 이상으로 인한 서버 성능 저하 대응](/work/cpu-thermal/)

## 요약

특정 제조사 서버 약 200대에서 CPU 온도가 비정상적으로 올라 성능이 떨어지고 응답 시간이 늘었다.
부하나 외부 환경 문제가 아니라는 걸 먼저 확인했고, 냉각 설정으로 증상을 누른 뒤,
제조사와 로그를 분석해 **iLO(BMC) firmware 버그**를 원인으로 찾았다.
최신 firmware 로 올려 온도와 성능이 정상으로 돌아왔다.

## 영향

- 대상: 특정 제조사 서버 약 200대
- 증상: CPU 온도 비정상 상승 → 성능 저하 · 응답 지연

## 원인을 좁힌 순서

1. **부하·외부 요인 배제** — 서버 환경과 부하를 확인하고 성능 모니터링 도구로 살펴, 과부하가 아닌 다른 원인이라고 판단했다.
2. **냉각 설정으로 증상 완화** — 서버 설정에서 Enhanced Cooling Mode 를 켜고, 팬 속도를 바꿔 가며 냉각 성능이 가장 좋은 지점을 찾았다.
3. **제조사와 로그 분석** — 제조사와 함께 상세 로그를 분석해 iLO firmware 버그를 확인했다.
4. **근본 조치** — iLO firmware 를 최신 버전으로 올려 CPU 온도와 성능을 정상화했다.

## 재발 방지

- 같은 조합(모델 · firmware)의 서버에 iLO firmware 를 미리 적용
- 냉각 설정(Enhanced Cooling Mode · 팬 속도)은 임시 완화책으로 보고, 근본 원인(firmware)을 따로 쫓는다

## 배운 것

- **온도 문제가 늘 냉각 부족은 아니다.** 팬을 제어하는 BMC firmware 가 원인일 수 있다. 부품이나 공조를 의심하기 전에 firmware 버전과 정책을 본다.
- **완화와 해결을 나눈다.** 냉각 설정으로 서비스를 먼저 살리고, 원인은 제조사 로그로 확정했다.
- 증상이 난 서버만 고치면 끝나지 않는다. **같은 조합을 가진 서버 전체**를 맞춰야 재발이 없다.

## GPU 노드에서는 어떻게 보이나

일반적인 내용으로, 이 사례를 GPU 클러스터에 옮기면 이렇다.

- GPU 는 뜨거워지면 스스로 clock 을 내린다(thermal throttling). 고장이 아니라 **느려지는 것**이라 놓치기 쉽다.
- `nvidia-smi -q -d PERFORMANCE` 의 Clocks Throttle Reasons(최근 드라이버에서는 Clocks Event Reasons)에서 `SW/HW Thermal Slowdown` 이 켜져 있는지 본다.
- DCGM 으로 GPU 온도와 throttle 사유를 계속 수집하면, 같은 랙 · 같은 모델에서만 느린 노드를 찾을 수 있다.
- 이번 사례처럼 **BMC · firmware 가 팬 제어를 좌우**한다. 고밀도 GPU 랙일수록 firmware 버전과 랙 단위 온도 편차를 함께 본다.
